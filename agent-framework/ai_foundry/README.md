# Azure AI Foundry Integration

Enterprise-grade agent management, monitoring, and observability for the Medical Affairs Multi-Agent System.

---

## 📁 Files

### `ai_foundry_integration.py`
Core integration module with:
- **`AIFoundryAgentRegistry`** - Local registry for demo mode (no Azure required)
- **`AzureAIFoundryClient`** - Production Azure connection
- **`AgentMetadata`** - Agent registration schema
- **`AgentInteraction`** - Interaction tracking schema

### `register_agents_ai_foundry.py`
Script for registering all Medical Affairs agents with Azure AI Foundry:
- Literature Scout Agent
- MI Orchestrator Agent
- Compliance Guard Agent
- GRADE Evidence Assessment Agent

Usage: `python register_agents_ai_foundry.py`

### `list_agents.py`
Lists all agents in your Azure AI Foundry project with details:
- Agent names and IDs
- Model configurations
- Creation timestamps
- Metadata and tools

Usage: `python list_agents.py`

### `delete_and_reregister_agents.py`
Deletes existing Medical Affairs agents and re-registers them with fresh configuration.
Use cases:
- Update agent model (e.g., gpt-4 → gpt-4o)
- Modify agent instructions
- Clean up duplicates

Usage: `python delete_and_reregister_agents.py`

### `AI_FOUNDRY_GUIDE.md`
Comprehensive documentation including:
- ✅ Feature overview and architecture diagrams
- ✅ Quick start guide (demo and production modes)
- ✅ Use cases (compliance audits, performance monitoring, cost tracking)
- ✅ Production deployment instructions

### `azure_agent_registration.json`
Agent registration metadata including agent IDs, endpoints, and timestamps (generated by registration scripts).

## 🚀 Quick Start

### Demo Mode (No Azure Required)

```python
from ai_foundry.ai_foundry_integration import setup_ai_foundry_tracking

# Initialize local registry
registry = setup_ai_foundry_tracking(project_name="medical-affairs-demo")

# Register an agent
agent_id = registry.register_agent(
    agent_name="Literature Scout Agent",
    agent_type="server",
    description="Searches medical literature for evidence",
    capabilities=["pubmed_search", "labeling_retrieval", "evidence_ranking"],
    endpoint="http://localhost:9100",
    tags={"domain": "medical_affairs", "criticality": "high"}
)

# Track interactions
registry.track_interaction(
    agent_id=agent_id,
    input_data={"query": "renal dosing for Drug X"},
    output_data={"evidence_count": 3, "confidence": 0.94},
    duration_ms=125.5,
    status="success"
)

# View metrics
metrics = registry.get_agent_metrics(agent_id)
print(f"Success Rate: {metrics['success_rate']:.1f}%")
```

### Test the Integration

```powershell
# Run the demo script
python ai_foundry/ai_foundry_integration.py

# Check generated files
cat ai_foundry_registry/agent_registry.json
cat ai_foundry_registry/foundry_export.json
```

## 📊 What Gets Tracked

### Agent Metadata
- Unique agent ID and name
- Type (orchestrator/server/validator)
- Capabilities and version
- Endpoint URL (for server agents)
- Registration timestamp
- Custom tags

### Interaction Data
- Input/output payloads
- Execution duration (ms)
- Success/error status
- Timestamps
- Custom metadata (compliance flags, risk levels)

### Performance Metrics
- Total call count
- Success rate (%)
- Average latency (ms)
- Error count
- Last interaction timestamp
